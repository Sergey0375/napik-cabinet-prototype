# Демонстрационный личный кабинет адвоката

Публичный прототип для проверки интерфейса: https://Sergey0375.github.io/napik-cabinet-prototype/

12 экранов: обзор, реестр дел, создание/редактирование дела, карточки дела и клиента, документы, карточка документа, подтверждение действия с документом, календарь, создание/редактирование события, подтверждение удаления события, журнал операций.

Главная страница открывает «Обзор». Основная навигация находится внутри кабинета; полный список экранов — в раскрываемой панели сверху. Адреса экранов используют `#/…`, поэтому прямые ссылки и обновление страницы работают на GitHub Pages.

## Ограничения

- Это статический прототип, не действующая информационная система.
- Сведения о клиентах и делах учебные. Не вводите реальные персональные данные.
- Нет серверной авторизации и базы данных, соединения с Telegram, Яндекс.Диском, почтой или ИИ.
- Сохранение, удаление, повтор операций и отправка в интерфейсе демонстрационные; они не изменяют реальные объекты.
- Возможны обозначенные в интерфейсе заглушки переходов и действий. Данные макета не предназначены для постоянного хранения.
- Сайт и исходный код общедоступны. `noindex` — рекомендация поисковым системам, а не защита доступа.

Опубликованная версия содержит только кабинет адвоката. Telegram-экраны, проектные документы и резервные копии не публикуются.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Все необходимые для макета ресурсы встроены в `index.html`; отдельной сборки и установки зависимостей не требуется.
